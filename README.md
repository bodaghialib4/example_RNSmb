# example_RNSmb
A sample usage of react-native-smb with React-native version 0.75.3


## running and testing specifications:

React-native: "0.61.2"
- node : v20.11.0
- java: 20.0.1

### correct node and java version In MacOS:
set node version to 14 with nvm:
```
nvm use 20.11.9
```

set java version to 20.0.1:
```
export JAVA_HOME=$(/usr/libexec/java_home -v 20.0.1)
```


## Running app on Android:
open Project folder in a terminal and run:
```
yarn install
```
```
yarn start
```


### important
The fist step in every new terminal is to check node and java version
